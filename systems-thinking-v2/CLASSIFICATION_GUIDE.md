# Analytical classification guide

Every material node, relationship, value transition, JTBD, DVO, and claim uses three independent classifiers.

## Epistemic status

| Status | Meaning |
|---|---|
| Supported | Directly supported for this analysis. Evidence traceability is tracked separately. |
| Inferred | Reasonably derived but not directly established. |
| Assumed | Modeled without sufficient empirical evidence. |
| Contested | Credible evidence or interpretations disagree. |
| Unresolved | A classification cannot yet be made responsibly. |

## Claim basis

| Basis | Meaning |
|---|---|
| Evidence | Direct source evidence is linked. |
| Legacy evidence synthesis | The prior analysis described the item as evidence-based, but source links still need to be registered. |
| Analytical inference | The item is reasoned from the model or available signals. |
| Group convergence | Team Zig approved the item as analytical direction or opportunity framing. Approval is not empirical evidence. |
| Model definition | The item is a controlled definition used to make the model internally consistent. |

## Decision status

| Status | Meaning |
|---|---|
| Active direction | Approved for use as the organizing analytical model. |
| Hypothesis | A future mechanism or pathway requiring validation. |
| Intended outcome | A desired downstream result whose causal pathway remains unproven. |
| Unresolved | No active decision has been made or evidence remains insufficient. |

## Combined interpretation

- `Assumed • Group convergence • Active direction` means the group approved the construct for modeling; it is not evidence-supported.
- `Assumed • Group convergence • Hypothesis` means a future mechanism is being explored; it is not committed architecture.
- `Inferred • Analytical inference • Unresolved` means the relationship is plausible but requires validation.
- `Supported • Legacy evidence synthesis • Unresolved` means the prior analysis treated the claim as supported, but source traceability is still pending.

The renderer must never infer epistemic status from line style. Structural, inferred, and future line treatments communicate map interpretation, while the classifiers communicate knowledge status and provenance.
